One-time setup

Connect your cloud account

Your Brew Log, Beans, and personal Recipes now live in a private cloud database so they sync across your phone and computer. That takes a couple of one-time setup steps before it'll work.

1. Create a free Supabase project

Go to supabase.com, sign up (free), and create a new project. Pick any name/region and set a database password (you won't need to remember it day-to-day).

2. Run the schema script

In your new project, open SQL Editor → New query, paste the contents of supabase/schema.sql (included in this app's folder), and click Run. This creates your tables and locks them down so only you can see your own data.

3. Create the photo storage bucket

The schema script already creates a private brew-photos storage bucket and its access policies for you — no extra steps needed here.

4. Copy in your project keys

In Supabase go to Project Settings → API. Copy the Project URL and the anon public key. Open js/supabase-config.js in this app's folder and paste them in:

const SUPABASE_URL = "https://your-project.supabase.co";
const SUPABASE_ANON_KEY = "your-anon-public-key";

Both values are safe to keep in this file — they only allow what the Row Level Security policies in schema.sql permit (a signed-in user can only ever see their own rows).

5. Reload and sign up

Save the file, refresh this page (or reopen index.html), and you'll be able to create your account and start syncing.
